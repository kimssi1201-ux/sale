# 픽앤샵 예시 화면

자동 수집 없이 사용자가 제공하는 상품 링크, 제품 이미지 1장, 짧은 구매유도글로 운영하는 정적 큐레이션 사이트 예시입니다.

## 파일

- `index.html`: 화면 구조
- `styles.css`: 반응형 디자인
- `manual.css`: 제품 이미지 1장 표시 보조 스타일
- `app.js`: 상품 카드, 검색, 카테고리 필터
- `products.json`: 수동 상품 입력 예시

## 상품 입력 방식

상품마다 아래 값만 교체합니다.

- `productUrl`: 제공받은 쿠팡파트너스 상품 링크
- `imageUrl`: 제품 이미지 1장 URL
- `copy`: 400~500자 내외 구매유도글

## 구매유도글 생성 프롬프트

아래 블로그 포스팅을 휴대폰 화면에서 빠르게 읽을 수 있게 400~500자 내외로 줄여줘.

대가성 문구, 제목, 핵심 제품 정보, 장점 3개, 상품 링크 2번, 짧은 구매 자극 문구, 해시태그 5개만 남겨줘.
불필요한 설명과 반복 문장은 모두 삭제하고, 바로 복사 가능한 본문으로 작성해줘.
