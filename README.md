# 픽앤샵 예시 화면

쿠팡파트너스 링크를 쇼핑몰처럼 정리하는 정적 큐레이션 사이트 예시입니다.

## 파일

- `index.html`: 화면 구조
- `styles.css`: 반응형 디자인
- `app.js`: 검색과 카테고리 필터
- `products.json`: API나 수동 상품 목록으로 바꿀 때 사용할 데이터 예시
- 상품 이미지는 `app.js`의 인라인 SVG와 `styles.css`의 배경 스타일로 표현합니다.

## 운영 메모

- 실제 상품 링크는 쿠팡파트너스 딥링크로 교체해야 합니다.
- 고지 문구는 사이트 상단이나 푸터처럼 사용자가 볼 수 있는 위치에 유지하는 편이 안전합니다.
- 가격, 배송, 할인율은 변동될 수 있으므로 고정 노출보다 쿠팡 상품 페이지 확인 방식이 안정적입니다.
